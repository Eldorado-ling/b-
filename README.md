## ✨ 功能特点

- 🎯 **多条件筛选**：支持按类别、价格区间、排序方式进行商品筛选
- 🔍 **智能过滤**：提供商品名称和价格上限的实时过滤功能
- 📊 **数据展示**：表格化展示爬取结果，支持排序和搜索
- 💾 **数据导出**：支持导出为 CSV 或 JSON 格式
- 🎨 **现代UI**：基于 CustomTkinter 的深色主题界面
- ⚡ **实时统计**：显示爬取数量、累计时间、请求耗时等实时数据
- 🔐 **Cookie管理**：方便的 Cookie 保存和配置功能
- 🌙 **主题切换**：支持明暗主题切换

## 🔧 使用说明

### 1. 配置 Cookie

1. 打开 B站魔力赏市集网站
2. 使用 Edge 或 Chrome 浏览器登录
3. 按 F12 打开开发者工具
4. 在 Application/存储 → Cookies 中复制 Cookie 值
5. 在程序的「🔑 Cookie」页面粘贴并保存

### 2. 开始爬取

1. 在「🏠 主页」选择筛选条件：
   - **类别**：选择商品类别（3C、周边、手办、模型等）
   - **排序**：选择排序方式（综合、升序、降序）
   - **价格**：选择价格区间

2. 可选：启用查询过滤
   - **商品名称过滤**：输入关键词，仅显示包含该关键词的商品
   - **价格上限过滤**：设置价格上限，仅显示低于该价格的商品

3. 点击「🚀 启动」按钮开始爬取

4. 实时查看统计数据：
   - 爬取数量
   - 累计时间
   - 请求耗时

### 3. 查看和导出数据

1. 切换到「📊 数据展示」页面查看爬取结果
2. 使用搜索框在已爬取数据中查找
3. 点击排序下拉菜单按价格排序
4. 点击「🔗 查看链接」直接访问商品页面
5. 在「⚙️ 设置」页面导出数据为 CSV 或 JSON

## ⚠️ 注意事项

1. **Cookie 有效性**：请确保使用的 Cookie 来自 Edge 或 Chrome 浏览器且未过期
2. **采集限制**：每日采集数据建议不超过 20,000 条，避免触发限制
3. **请求频率**：程序已内置 3 秒请求间隔，请勿修改以避免被封禁
4. **数据保存**：程序配置和 Cookie 会自动保存到 `config.json` 文件

### 导出的 CSV 格式

```csv
name,price,link
商品名称,价格,商品链接
```

## 🔍 常见问题

### Q: 爬虫无法正常工作？
A: 请检查以下几点：
- Cookie 是否正确配置且未过期
- 网络连接是否正常
- 是否触发了频率限制（重新登录或等待后重试）

### Q: 如何获取更多数据？
A: 
- 默认情况下会爬取最多 20,000 条数据
- 使用关键词搜索时限制为 200 条
- 可以通过多次运行、不同筛选条件来获取更多数据

### Q: 程序卡顿或无响应？
A: 
- 爬虫在后台线程运行，不会阻塞界面
- 大量数据展示可能会稍有延迟，这是正常现象
- 建议定期导出数据并清空以保持性能
